Sobre este sitio web

Este sitio web es publicado por Caribbean Public Solutions, una firma de asesoría con sede en Bonaire.

Los datos de registro y de contacto se publicarán en esta página.

Datos personales

Este sitio web no utiliza cookies, herramientas de analítica ni tecnologías de seguimiento.

Por ahora, el formulario de contacto prepara una descripción del proyecto en su propio dispositivo. Sus datos no se transmiten a nosotros ni a terceros. Si decide compartir la descripción con nosotros, utilizaremos sus datos únicamente para responder a su consulta.

Preferencias guardadas en su navegador

Si desactiva el movimiento, esa preferencia se guarda en el almacenamiento local de su navegador para que el sitio la recuerde. Nunca se envía a ningún lugar y puede eliminarla borrando los datos de su navegador.

Fuentes, scripts y datos cartográficos

Todas las fuentes y los scripts se sirven desde este mismo sitio web; no se carga contenido de servicios externos.

El mapa se basa en datos de Natural Earth, que son de dominio público. Fuentes: Fraunces e Inter Tight (SIL Open Font License). Renderizado 3D: three.js (licencia MIT).

Aviso legal

La información de este sitio web es de carácter general y no constituye asesoría jurídica. Procuramos mantenerla exacta, pero no genera derechos de ningún tipo.
