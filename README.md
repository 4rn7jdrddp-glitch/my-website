# Caribbean Public Solutions — website

Static, multilingual website (English, Spanish, Dutch, Papiamentu) with a scroll-driven Three.js scene of the Caribbean, Bonaire highlighted as home base.

- `/en/`, `/es/`, `/nl/`, `/pap/` — one page per language (separate URLs, `hreflang` alternates, translated metadata, form, validation and accessibility labels).
- `/{lang}/privacy/` — privacy & legal information.
- `/` — language gateway (redirects on browser language, links without JavaScript).

## Structure

| Path | Purpose |
| --- | --- |
| `src/i18n/*.js` | All copy, one file per language, identical structure (`en.js` is the source). |
| `src/config.js` | Site URL and contact endpoint — only fill in confirmed values. |
| `src/data/map.json` | Simplified Caribbean geography from Natural Earth (public domain), generated by `npm run geo`. |
| `src/data/places.js` | Places used to illustrate the working area (not offices). |
| `src/js/main.js` | UI: motion setting, navigation, language links, region selector, services/process tracking, principles, lazy 3D. |
| `src/js/form.js` | Contact form validation, spam limitation, project brief (copy/download) or endpoint submission. |
| `src/js/scene.js` | Three.js scene: one renderer, five narrative states blended by native scroll. |
| `src/css/site.css` | All styles (tokens on `:root`). |
| `scripts/build.mjs` | Renders the HTML for every language into `docs/`, bundles JS with esbuild, copies fonts. |
| `docs/` | Built site, ready for GitHub Pages (Settings → Pages → branch, folder `/docs`). |

## Commands

```bash
npm install
npm run build   # writes docs/
npm run serve   # http://localhost:8080
npm run geo     # only when regenerating the map data
```

## Before going live

1. Set `siteUrl` in `src/config.js` (canonical, hreflang and sitemap then use absolute URLs).
2. Connect a form endpoint via `contactEndpoint` (JSON POST, 2xx = success). Until then the form clearly works as a local project brief; nothing is sent.
3. Add confirmed contact and registration details to the legal page (`legal` in the language files).
4. Have the Papiamentu (and ideally the Spanish) copy reviewed by a native speaker.

## Motion, performance and fallbacks

- Native scrolling only; the scene follows scroll position. Sticky elements are limited to the service index, phase navigation and headings.
- A visible Motion on/off control (header + footer), stored in `localStorage`; `prefers-reduced-motion` switches motion off by default.
- The 3D bundle is loaded after page load when the browser is idle, only if WebGL is available and Save-Data is off. Rendering pauses when no 3D section is on screen or the tab is hidden; with motion off, frames are rendered only on change.
- Mobile uses lighter geometry, no particles, no bevels and a lower pixel ratio.
- Without WebGL or JavaScript a static SVG map (generated from the same data) is shown and all content remains readable.
